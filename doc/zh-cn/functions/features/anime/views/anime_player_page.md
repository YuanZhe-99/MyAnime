# lib/features/anime/views/anime_player_page.dart

优先原生播放，以代次标识隔离异步结果，限定解析和启动时间，立即释放解码器，并单向回退网页。清理错误不会阻断回退。依赖注入支持确定性生命周期测试。网页失败时提供浏览器入口，不循环重试。

自 1.6.5 起，原生播放在视频之上绘制 [`anime_player_controls.dart`](anime_player_controls.md)，并通过 `PlaybackProgressService` 记录同步的续播位置：媒体每前进五秒、暂停时，以及在 `_release` 中释放解码器之前——这涵盖了离开、切换分集和回退到网页。超过 95% 时删除该条目，带编号的集会被标记为已看，每次会话一次。首次得知时长时，已存的续播位置被应用一次，并由提示条提供从头播放。从菜单选择的速度沿用到本次会话的下一集。网页播放器不记录任何内容，没有 `animeId` 时也不记录。

## 声明

| 声明 | 层级 | 用途 |
|---|---|---|
| `AnimePlaylistEntry` | B | 把分集页面与其本地集数配对（1.6.5） |
| `AnimePlayerPage` | B | 创建原生优先播放页，支持注入可测试的平台依赖 |
| `createState` | B | 创建播放生命周期状态 |
| `initState` | B | 仅在完整版开始播放用户请求的分集 |
| `_trackKey` | B | 当前解码器所播放分集的进度键（1.6.5） |
| `_flush` | B | 记录所跟踪分集最后已知的位置（1.6.5） |
| `_release` | B | 先保存进度，再立即停止解码器并取消监听器与计时器 |
| `_start` | B | 尝试有界原生播放，忽略旧代次异步结果 |
| `_applyResume` | B | 跳转到已存的续播位置，仅一次（1.6.5） |
| `_fallback` | B | 释放原生播放器后单向回退到同一集网页 |
| `dispose` | B | 路由退出时取消旧代次并释放资源 |
| `build` | B | 显示原生或网页播放器，以及选集和外部打开入口 |

## 契约

输入、结果及副作用参见[观看链接行为](../../../../features/watch-url-lookup.md)与源码结构化注释。网络解析支持注入客户端，映射为确定性计算。播放器对象和临时凭据不会被序列化。
