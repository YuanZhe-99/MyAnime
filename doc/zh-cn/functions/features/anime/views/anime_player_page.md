# lib/features/anime/views/anime_player_page.dart

优先原生播放，以代次标识隔离异步结果，限定解析和启动时间，立即释放解码器，并单向回退网页。清理错误不会阻断回退。依赖注入支持确定性生命周期测试。网页失败时提供浏览器入口，不循环重试。

## 声明

| 声明 | 层级 | 用途 |
|---|---|---|
| `AnimePlayerPage` | B | 创建原生优先播放页，支持注入可测试的平台依赖 |
| `createState` | B | 创建播放生命周期状态 |
| `initState` | B | 仅在完整版开始播放用户请求的分集 |
| `_release` | B | 立即停止解码器并取消监听器与计时器 |
| `_start` | B | 尝试有界原生播放，忽略旧代次异步结果 |
| `_fallback` | B | 释放原生播放器后单向回退到同一集网页 |
| `dispose` | B | 路由退出时取消旧代次并释放资源 |
| `build` | B | 显示原生或网页播放器，以及选集和外部打开入口 |

## 契约

输入、结果及副作用参见[观看链接行为](../../../../features/watch-url-lookup.md)与源码结构化注释。网络解析支持注入客户端，映射为确定性计算。播放器对象和临时凭据不会被序列化。
