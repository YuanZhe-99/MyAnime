# lib/l10n/ — Generated Localization Code

The four files in `lib/l10n/` (`app_localizations.dart`, `app_localizations_en.dart`,
`app_localizations_ja.dart`, `app_localizations_zh.dart`) are generated by Flutter's `gen-l10n`
tool from the ARB templates (`app_en.arb`, `app_ja.arb`, `app_zh.arb`, `app_zh_TW.arb`). They are
tracked in source control but not hand-written, and — unlike every other file in this repository —
they carry no `/// Purpose:` Function Explanation Layer comments (confirmed: `grep -rc 'Purpose:'
lib/l10n/` reports zero matches across all four files, versus 660 across the rest of `lib/`).

Each locale subclass (`AppLocalizationsEn`, `AppLocalizationsJa`, `AppLocalizationsZh`) implements
the abstract `AppLocalizations` base class with one trivial string/plural getter per translatable
key defined in the ARB templates — hundreds of near-identical one-line Tier B getters. Because
they are generated, not authored, and contain no algorithm or usage beyond "return a localized
string for this key," this documentation set does not enumerate them individually. The canonical,
human-maintained source of truth for the string catalog is `lib/l10n/app_en.arb` (the template ARB
file); regenerate this code with `flutter gen-l10n` after editing any ARB file, per this repo's
`AGENTS.md`.
