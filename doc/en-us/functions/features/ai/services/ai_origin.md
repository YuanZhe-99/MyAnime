# lib/features/ai/services/ai_origin.dart

## Declarations

| Declaration | Purpose |
|---|---|
| `onlineSourceOf` | The online source id inside a stored model identity (`online:model:…`, or `provider:…` from 1.8.11), or null for an on-device result |
| `aiGeneratedLabelFor` | The "generated by" note for a result: `aiGeneratedLabel` on this device, `aiGeneratedOnlineLabel` naming the source online (looked up through the router, for both old and new ids), `aiGeneratedOnlineUnknownLabel` when that source was removed |

Added in 1.8.12 (`onlineProviderOf` became `onlineSourceOf` in 1.9.0). The identity is what
`modelIdentityOf` returned when the result was generated; it is stored with AI categories
(`AiCategoryEntry.model`) and related-list reasons (`RelatedItem.aiReasonModel`). A result without one
counts as on-device.
