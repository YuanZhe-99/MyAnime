# lib/features/ai/services/ai_origin.dart

## Declarations

| Declaration | Purpose |
|---|---|
| `onlineProviderOf` | The online provider id (`provider:…`) inside a stored model identity, or null for an on-device result |
| `aiGeneratedLabelFor` | The "generated by" note for a result: `aiGeneratedLabel` on this device, `aiGeneratedOnlineLabel` naming the provider online, `aiGeneratedOnlineUnknownLabel` when that provider was removed |

Added in 1.8.12. The identity is what `modelIdentityOf` returned when the result was generated; it
is stored with AI categories (`AiCategoryEntry.model`) and related-list reasons
(`RelatedItem.aiReasonModel`). A result without one counts as on-device.
