# lib/features/ai/services/insight_language.dart

`InsightLanguage` (1.9.1, ported from MyDevice!!!!!): the request language for the UI locale — Simplified or Traditional Chinese (converted to the UI variant), Japanese or English — and the Chinese variant conversion of each validated line.

## Declarations

| Declaration | Kind | Tier | Purpose |
|---|---|---|---|
| `InsightLanguage` | declaration | B | Create an insight language. |
| `forLocale` | declaration | B | Pick the request language for the UI locale. |
| `finish` | declaration | B | Post-process a validated line. |

`grep -c 'Purpose:' lib/features/ai/services/insight_language.dart` reports 3, one row each.
