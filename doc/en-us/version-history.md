# Version history

Release-by-release summary of MyAnime!!!!!. Useful for understanding *why* a behavior exists before
changing it — several entries record deliberate safety fixes that look like quirks otherwise.

## Repository caveat

The latest release tag before the documentation guide was added was `v0.6.7`, with `origin/master`
and `github/master` aligned there. Early history has one wrinkle: two root commits share the same
content after an early `git commit --amend`, and tag `v0.1.0` points to the later root. **Avoid
`git commit --amend` on root commits.**

- `v1.3.1`: Fixed the custom storage-path migration. Changing the storage folder previously moved only `anime_data.json`, stranding `images/`, `.sync_base/`, `backups/` (bundles and blobs), and `webdav_config.json` at the old location. The worst consequence was silent: without `.sync_base/` the next sync has no base snapshot, so records other devices had deleted read as "new locally" and were re-uploaded, resurrecting deletions across every device; losing `webdav_config.json` also stopped sync entirely, which disabled the image sync that would otherwise have repaired the missing covers. Migration now moves the **entire** storage folder except `storage_config.json` (which must stay put — it holds the path itself), so a data file added in a future release migrates with no code change. Existing destination files still win, and their source copies are now left in place rather than discarded. Shared logic lives in `myapps_data` `v1.0.1` as `migrateStorageContents`, covered by eight tests. Versions unified to `1.3.1+49` / MSIX `1.3.1.0` / installer `1.3.1`.
