# on_device_ai_apple

A local Flutter plugin used only by MyAnime!!!!!. On iOS 26 and macOS 26 or
later it answers the `com.yuanzhe.my_anime/genai` method channel with Apple's
on-device Foundation Models framework; on older systems it answers
`unsupported`. FoundationModels is weakly linked so the app still launches on
iOS 18 and macOS 15.

Documentation lives in the app repository: `doc/en-us/on-device-ai.md`.
